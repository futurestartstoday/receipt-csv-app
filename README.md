# レシートCSV

レシート画像から「品目・金額・税額」を読み取り、CSVで保存するWebアプリです。

## 特徴
- **各利用者のブラウザ内で完結**：OCR（文字読み取り）も生成AIも利用者のPC上で動きます。画像や読み取り結果はサーバーに送信・保存されず、他の利用者と共有されることもありません。
- **無料**：有料APIを使いません。
  - OCR：[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) の日本語対応モデル（文字検出: PP-OCRv5 mobile、文字認識: PP-OCRv6 small。いずれも Apache-2.0）を [paddleocr.js](https://github.com/x3zvawq/paddleocr.js)（MIT）と ONNX Runtime Web でブラウザ内実行。モデルは `models/` に同梱（約26MB）
  - 生成AI：[WebLLM](https://github.com/mlc-ai/web-llm) でオープンモデル Qwen2.5-1.5B-Instruct をブラウザ内で実行（任意・WebGPU対応ブラウザのみ）
- **サーバー不要**：HTML/CSS/JavaScriptだけの静的サイトのため、多くの人に使われても公開者に費用や負荷はかかりません。

## 使い方
1. レシート画像をドロップ（またはクリックして選択）。JPEG・PNG・HEIC（iPhoneの写真）・PDF（iPhoneの書類スキャンなど）に対応しています。拡張子ではなくファイルの中身で形式を判断するので、拡張子が「.jpeg」でも中身がHEICの画像も読めます
2. 半角カナのレシートなどで品名の誤字が多いときは「高精度モード」にチェック（または読み取り後に「直前の画像を高精度モードで読み直す」）。画像を横に1.5倍に引き伸ばしてから読み取ることで、幅の狭い半角カナを読み違えにくくします。金額が小計と合わない場合は通常の読み取り結果と比べて、合う方を使います
3. 必要なら「生成AIで品目を整理する」にチェック（初回のみ約1GBのモデルをダウンロードします。2回目以降はブラウザのキャッシュから読み込みます）
4. 表で品目・金額・税率を確認・修正（税額は自動計算、手修正も可）
5. 「CSVをダウンロード」

CSVの形式（BOM付きUTF-8・Excelでそのまま開けます）:
```
品目,金額,税額
牛乳 1000ml,238,17
```

## ローカルで動かす
`index.html` を直接ダブルクリックするとブラウザの制限で動かないため、簡易サーバーで開きます。
いちばん簡単なのは **`start.bat` をダブルクリック**することです（サーバーが起動し、ブラウザが開きます）。
```
npm start          # http://localhost:3000 を開く
# または
python -m http.server 8000   # http://localhost:8000 を開く
```

テスト: `npm test`

## 公開（GitHub Pages）
1. GitHubでリポジトリを作成し、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`<meta name="robots" content="noindex">` を指定しているため検索エンジンには載りません。URLを知っている人だけが使える形になります。

## 注意
- 外部から読み込むのはライブラリ本体（jsDelivr。HEIC変換の heic-to（LGPL-3.0）、PDF表示の pdf.js（Apache-2.0）は必要なときだけ読み込み）と生成AIのモデルデータ（Hugging Face）だけで、レシートの内容は送信しません。
- 軽減税率の※印はOCRで読めないことが多いため、レシートの「8%対象 ¥○○」の金額と合計が一致する品目の組み合わせから8%の品目を推定します。
- 読み取り結果はページを閉じると消えます（ブラウザにも保存しません）。
- 生成AIの整理はWebGPU対応ブラウザ（Chrome/Edgeの最新版など）が必要です。非対応の場合はルールベースで読み取ります。
- 読み取り精度は画像の明るさ・傾きに左右されます。必ず表で内容を確認してください。
